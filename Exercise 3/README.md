## About the Data

### Data Source

For this project, I used the dataset that contains information about the televisions brand and its models; it also contains the **energy consumption charcteristics** such as screen technology, the energy used,star ratings.

The dataset that used as attached below:
https://reg.energyrating.gov.au/comparator/product_types/32/search/?expired_products=on

### Data Processing
Before I started to explore the data and get the insights, I was preprocessed the data to ensure it was suitable for analysis. For instance, I applied:
- Remove inrrelevant columns (eg. Product Website and Representative Brand Website)
- Replace missing values with N/A or remove entire rows since there were only a few row for that data.
- Add a new column that convert screen size from cm to inches.
- Convert brand names to uppercase.
- Used only relevant attributes for visualisation.

### Privacy
This dataset does not contain any **Personally Identifiable Information (PII)**. It only consists the product specifications and energy consumption data based on multiple conditions that related to the televisions devices.

### Accuracy and Limitations
This dataset I used is get from official Australia government wbesite, which indicates that its accuracy has been verified by the Australia government. 

While the accuracy of the dataset has been verified, there are still some limitations to consider:
- The dataset may not include **all television models available in the Australia market**
- The information of certain TVs may be outdated or contain missing values.
- Energy consumption may be differ as compared real-word usage.

Those factor should be considered when creating the visualisations.

### Ethics
When presenting data visualisations, I have ensured the information is represented **accurately, fairly and responsibly**. For instance, I applied ethical data practices by:
- Avoid bias visualisation that could mislead viewer toward the creator's preferences.
- Ensuring the data used for the data visualisation is transparent, so viewers can verify the information themselves.
- Presenting information clearly in the visualisations, so viewers can easily understand the meaning of each graph.
