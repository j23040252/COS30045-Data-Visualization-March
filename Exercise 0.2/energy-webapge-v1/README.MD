# Exercise 0.2 Website - Australian Appliance Energy Hub

## Overview

This website was built for Exercise 0.2 and contains three pages:
- Home
- Televisions
- About Us

## Requirement Checklist

- Three pages created: Home, Televisions, About Us.
- Top navigation menu allows switching between pages using JavaScript click handling.
- Power logo is shown in the top-left and clicking it returns the user to Home.
- Mouse over feedback is provided for the logo and navigation menu items.
- Active page feedback is shown through highlighted navigation state.
- Styling is implemented in a dedicated CSS file with colours matched to the provided logo.
- Footer is included on all pages with year, student name placeholder, and GenAI acknowledgement.
- Placeholder content and sample data are included for appliance energy consumption in Australia.
